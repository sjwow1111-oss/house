# 산들 · Three.js 주택 맵

참고 사진의 어두운 벽돌, 밝은 타일로 마감한 2층 주택, 큰 창과 차양,
석재 하부 외벽, 중앙 계단, 검정 난간, 잔디 정원과 산 능선을 반영한 브라우저용 맵입니다.

## 실행

Node.js 22.12 이상 또는 24와 npm이 필요합니다.

```sh
cd /workspace/house
npm ci --cache /workspace/.npm-cache
npm run dev -- --port 5173
```

프로덕션 빌드는 `npm run build`, 빌드 결과 확인은 `npm run preview`입니다.
외부 API 키나 서버는 필요하지 않습니다. 폰트와 Three.js는 로컬 패키지에 포함됩니다.

## 탐방과 조작

- 둘러보기: 마우스 드래그로 회전, 휠 또는 터치 핀치로 확대합니다.
- 직접 탐방: 안내에서 **정원에서 시작**을 누릅니다. 마우스 잠금이나 별도 연결 없이 실행됩니다.
- 모바일: 왼쪽 조이스틱으로 전진·후진·좌우 이동, 나머지 화면을 드래그해 시선을 조절합니다.
  두 손가락으로 이동과 시선 조절을 동시에 할 수 있습니다. 손을 떼거나 터치가 취소되면 이동이 멈춥니다.
- 데스크톱: WASD / 방향키로 이동, Space로 점프, Shift로 달리기, 화면 드래그로 시선을 조절합니다.
- 모바일: 점프 버튼으로 점프하고 달리기 버튼으로 달리기 모드를 켜고 끕니다.
- 환경 설정의 **달리기 속도**에서 3–10 m/s를 조절할 수 있으며 선택한 속도는 브라우저에 저장됩니다.
- 플레이어의 몸은 1인칭 화면을 가리지 않고 태양 및 실내 조명에 실제 그림자를 드리웁니다. 이동·점프 시 그림자도 함께 움직입니다.
- **집 안으로 들어가기**는 거실에서 탐방을 시작합니다. **공간 바로가기**로 원하는 방에 바로 이동할 수 있습니다.
- 현관문과 거실 유리문은 가까이 다가가면 자동으로 열립니다. 현관의 실제 계단으로 2층에 오르내릴 수 있습니다. 계단 위쪽 착지 공간과 가구 사이 통로를 확보했습니다.
- **둘러보기로** 또는 Esc로 탐방을 종료합니다. 모바일 가로 화면도 지원합니다.
- 환경 버튼에서 낮 / 오후 / 밤, 노출, 실내 조명 및 잔디 바람을 조절합니다.

| 2층 | 게스트룸 | 침대·침구, 수납장·협탁·조명, 작은 책상·의자·러그 |

문·창문·계단·난간·바닥·천장·벽은 실제 형상으로 만들었습니다.
방과 가구는 평면 이미지가 아닌 절차적으로 생성한 3D 메시입니다.
사진을 참고한 모델이며 실제 건물의 실측 구조는 아닙니다. 거울은 환경 반사 재질이며 실시간 방 반사 렌더링은 사용하지 않습니다.
서랍과 가전은 장식 모델입니다. 현재 개폐 애니메이션은 현관문과 거실 슬라이딩 문에 적용됩니다.

## 구현과 성능

- `src/main.js`: 렌더러, 풍경, 시간대, 재질 생성 및 정적 메시 병합.
- `src/world/house.js`: 실제 주택 구조와 방별 세부 모델, 문 애니메이션, 조명과 목적지.
- `src/world/doors.js`: 현관의 경첩과 양면 손잡이, 유리문의 별도 레일·프레임·이동 중 충돌.
- `src/world/movement.js`: 높이를 고려한 플레이어 충돌, 이동 분할, 계단과 층별 바닥 추적.
- `src/navigation.js`: 터치 조이스틱과 멀티터치 시선, 점프·달리기 설정, 키보드 및 탐방 UI.
- `src/player-shadow.js`: 그림자용 플레이어 몸체와 발밑 접촉 그림자.

알베도·범프·거칠기, 오크 나뭇결·직물·대리석 패턴, 환경 반사, 부드러운 그림자 및 ACES 톤 매핑을 사용합니다.
정적인 모델은 재질과 공간별로 병합하고 잔디는 인스턴싱합니다.
모바일은 잔디 42,000개, DPR 최대 1.25를 사용하며 데스크톱은 각각 90,000개·1.7입니다.
광원과 그림자 카메라는 방별로 고정하고 계단 이동 시 층별 조명 밝기를 부드럽게 전환합니다.
얇은 장식의 그림자 노이즈와 문 유리의 겹치는 면을 줄이고, 시스템의 동작 줄이기 설정을 존중합니다.
가구는 앞면 방향과 벽 간격을 함께 관리하며, 창문과 가구가 겹치지 않도록 창 위치를 조정했습니다.
벽은 문·창문 개구부를 가진 연속된 형상으로 만들고, 높이가 다른 외벽과 실내 칸막이의 중복 면을 제거했습니다.
문 유리는 한 장의 면으로 렌더링하고 고정창과 이동창의 깊이를 분리합니다. 문짝이 열려도 실제 위치의 충돌은 유지됩니다.
계단의 각 단 높이와 이동 바닥 높이가 일치하며, 뒤쪽의 접근 불가능했던 공간은 구조체로 막았습니다.

## 검증

```sh
npm test               # 실제 주택의 방 연결·문·계단·점프·충돌·조명 안정성 검증
npm run test:smoke     # 개발 서버가 켜진 상태에서 브라우저 검증
npm run test:visual    # 개발 서버에서 집 안팎 23개 시점의 화면 저장
```

브라우저 검증에는 시스템 Chromium(`/usr/bin/chromium`) 또는 `CHROMIUM_PATH`가 필요합니다.
데스크톱 이동과 시선, 자동 문, 모든 공간, 점프·달리기 조절·플레이어 그림자, 조명·노출과 종료를 확인하고,
모바일에서 실제 터치 이벤트로 조이스틱과 시선을 동시에 조작합니다.
터치 해제·취소, 실내 진입, 화면 회전 및 탐방 종료도 확인합니다.
`TEST_BASE_URL`로 검증할 서버를 바꿀 수 있습니다.
스크린샷은 저장소 외부 `/workspace/artifacts`에 저장됩니다.
공간별 화면은 `/workspace/artifacts/audit/after`에 저장됩니다. 시점 제어 기능은 개발 모드에만 제공되며 배포 빌드에는 포함되지 않습니다.

## Cloudflare Workers 배포

`wrangler.jsonc`는 `house` Worker에서 `dist` 정적 파일을 제공하도록 설정되어 있습니다.
브라우저가 Three.js를 실행하므로 서버 측 WebGL이나 별도 Worker 코드는 필요하지 않습니다.

```sh
npm run deploy:check  # 빌드 및 업로드 없는 배포 패키지 검증
npm run deploy       # 빌드 후 실제 Workers 배포
```

실제 배포에는 Cloudflare 인증이 필요합니다. 로컬 PC에서는 `npx wrangler login`을 사용합니다.
자동화 환경에서는 환경 설정에 `CLOUDFLARE_API_TOKEN`을 비밀 값으로 저장하고
`CLOUDFLARE_ACCOUNT_ID`에 배포할 계정 ID를 설정합니다. API 토큰에는 해당 계정의
Workers Scripts Edit 권한이 필요합니다. 토큰을 코드나 Git에 넣지 마세요.
이 클라우드 환경에서는 `XDG_CONFIG_HOME=/workspace/.config`를 사용하고
`WRANGLER_LOG_PATH=/workspace/house/.wrangler/logs`로 로그를
쓰기 가능한 위치에 저장하고 `WRANGLER_SEND_METRICS=false`를 사용할 수 있습니다.

GitHub 연동으로 자동 배포하려면 Cloudflare Workers & Pages에서 저장소
`sjwow1111-oss/house`, 브랜치 `main`을 연결하고 빌드 명령은 `npm run build`,
배포 명령은 `npx wrangler deploy`로 설정합니다. 최초 배포 성공 후 출력되는
Workers URL에서 WebGL 화면과 정적 자산을 확인하세요.
